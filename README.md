# 🪳 바퀴벌레 포커 온라인

브라우저로 여럿이 즐기는 온라인 바퀴벌레 포커 (Node.js + WebSocket)

거짓말을 던지고, 거짓말을 간파하세요. 방 코드만 공유하면 친구들과 바로 할 수 있고, 사람이 모자라면 봇을 추가해서 즐길 수 있습니다.

## 특징

- 2~6명, 사람 + 봇 혼합 가능
- 방 코드 / 초대 링크로 입장
- 새로고침하거나 연결이 끊겨도 재접속 가능 (끊긴 동안은 봇이 대신 진행)
- 게임 도중 나가면 봇이 그 자리를 이어받음
- 모바일 브라우저 지원

## 실행

```bash
npm install
PORT=3000 npm start      # PORT를 생략하면 3000번
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.

> `node_modules` 폴더는 저장소에 포함되어 있지 않습니다(`.gitignore` 처리). 받은 뒤 `npm install`을 한 번 실행하면 `package.json` / `package-lock.json` 기준으로 필요한 모듈(`ws`)이 설치됩니다.

## 규칙 요약

- 8종류 벌레 카드 × 8장 = 64장을 인원수대로 나눠 가집니다.
- 목표: 같은 벌레 카드를 **4장** 모으면 패배! 내 차례에 낼 카드가 없어도 패배입니다.
- **내 차례**: 손패에서 카드 한 장을 뒷면으로 골라 한 명에게 건네고 "이건 ○○야" 또는 "이건 ○○가 아니야"라고 말합니다. 거짓말도 가능합니다.
- **카드를 받으면**
  - 맞아: 말이 사실이라고 믿기
  - 거짓말!: 사실이 아니라고 의심하기
  - 몰래 보고 넘기기: 카드를 확인한 뒤, 아직 안 본 사람에게 새로 말하며 넘기기 (마지막 사람은 넘길 수 없음)
- **결과**: 판단이 틀린 쪽이 그 카드를 자기 앞에 공개하고 가져갑니다. 가져간 사람이 다음 차례입니다.
